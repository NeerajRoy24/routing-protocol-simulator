Theoretical Foundations & Algorithm Mechanics

Understand the mathematical guarantees behind Cisco's DUAL algorithm and IETF's Path Vector BGP standard.

1. DUAL (EIGRP) Mathematics

DUAL prevents loops by constructing a Directed Acyclic Graph (DAG) for each destination. A neighbor $k$ qualifies as a Feasible Successor (FS) if its Reported Distance is strictly less than the router's current Feasible Distance:

$$\text{RD}_k < \text{FD}_{\text{local}}$$ Guarantees neighbor cannot route back through local node
$$\text{Composite Metric} = 256 \times \left(\frac{10^4}{\text{BW}_{\text{Mbps}}} + \frac{\text{Delay}_{\text{ms}}}{10}\right)$$

2. Path Vector (BGP) Policy Order

BGP acts as the postal routing system of the global Internet. It chooses routes based on administrative policies rather than physical performance:

1. Highest LOCAL_PREF Policy Weight (default 100)
2. Shortest AS_PATH Fewer AS traversals
3. Lowest Origin Code IGP < EGP < Incomplete
4. Lowest MED / IGP Metric Internal tie-breaker
AS-Path Loop Check: If a router receives an update containing its own Autonomous System number in the AS_PATH attribute, it silently discards the advertisement to avoid loop formation.

How to Run Locally on your Machine

Method 1: Quick Batch Execution
# In project root folder:
.\run.bat
Automatically uses the isolated virtual environment (`venv`) and produces console benchmarks and the PNG graph.
Method 2: Direct Python Command
# Run via python interpreter:
python simulator.py
Requires `networkx`, `matplotlib`, and `numpy` installed from `requirements.txt`.
